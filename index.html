        Bestätigen

        Datenschutz

        Der Helferplan dient ausschließlich der Organisation von Helfer-Schichten beim Vereinsfest.

        Welche Daten werden gespeichert?

        Es wird nur der von dir eingegebene Name gespeichert. Der Name ist öffentlich im Schichtplan sichtbar. Kontaktdaten, Adressen, Geburtsdaten oder Zahlungsdaten werden nicht erhoben.

        Wo werden die Daten gespeichert?

        Die Daten werden in einer Firebase Realtime Database von Google gespeichert. Firebase wird als Auftragsverarbeiter eingesetzt. Weitere Informationen enthält die Datenschutzerklärung von Firebase.

        Wie lange werden die Daten aufbewahrt?

        Die Einträge bleiben bis zum Zurücksetzen durch den Admin gespeichert. Das technische Änderungsprotokoll (Audit-Log) wird nach Abschluss der Veranstaltung empfohlenermaßen gelöscht.

        Löschung

        Einträge können jederzeit über den Stift im Schichtplan geändert oder gelöscht werden. Der Admin kann alle Einträge zurücksetzen.

        Es werden keine Cookies, kein Tracking und keine Analyse-Dienste eingesetzt.
