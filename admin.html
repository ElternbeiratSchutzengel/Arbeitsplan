        Bestätigen

        Passwort vergessen?

        Der Admin-Zugang ist ein UI-Schutz ohne Server-Authentifizierung. Eine automatische Passwort-Zurücksetzung per E-Mail gibt es nicht. So setzen Sie das Passwort zurück:

        1. Öffnen Sie die Verwaltungsoberfläche.
        2. Löschen Sie unter config die Felder adminHash und adminSalt.
        3. Laden Sie diese Seite neu. Es erscheint wieder die Erstvergabe.
        4. Vergeben Sie ein neues, starkes Passwort.

        Diese Anleitung steht auch im README. Der Zugriff auf die Verwaltungsoberfläche ist dabei die eigentliche Sicherheitsgrenze.
